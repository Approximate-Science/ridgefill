# RidgeFill project page

Source of https://approximate-science.github.io/ridgefill/, the project page for *RidgeFill: Training-Free Late-Layer
Cache Fill for Faster Prefill* by Dylan Johnston and Robert P Smith (preprint, 2026,
[doi:10.5281/zenodo.23890247](https://doi.org/10.5281/zenodo.23890247);
[OpenReview](https://openreview.net/forum?id=ymLpDkJIGs)).

A single static page (`index.html`) with the paper's PDF and figures in `assets/`. Every number on the page is
copied from the paper. The paper and its figures are licensed under CC BY 4.0.

- Code: [Approximate-Science/llama.cpp-ridgefill](https://github.com/Approximate-Science/llama.cpp-ridgefill)
- Data and recompute scripts: [Approximate-Science/ridgefill-data](https://github.com/Approximate-Science/ridgefill-data)
- Maps: [huggingface.co/TheCacheIsALie](https://huggingface.co/TheCacheIsALie)
